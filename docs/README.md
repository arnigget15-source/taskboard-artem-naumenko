# Dokumentacja

Folder zawiera dokumentację projektu TaskBoard, instrukcje zadań i materiały do testowania.

- api.md – opis tras API, parametrów i przykładów JSON.
- testy.md – scenariusze testów API i interfejsu; wyniki należy uzupełnić po wykonaniu.
- postman/ – kolekcje żądań do testowania API.
- zadania/ – treści zadań realizowanych w kolejnych etapach.
